# 财报问答知识库（作业 A）

第三课作业 3 · 方向 A：同一批财报（10 家白酒公司 2026 半年报），建一个**答案带出处**的问答知识库。

## 数据与规模

- 10 家白酒公司 2026 年半年度报告全文 PDF（巨潮资讯下载，脚本见 `下载财报.py`）
- 解析切块：**3,321 块**，每块带 `公司 / 章节 / 页码` 元数据；表格按行列还原（"项目 | 本期 | 上年同期 | 增减%"）
- 财报 PDF 不入仓库（作业要求），拉取仓库后先运行 `python 下载财报.py` 重建 `数据源/`

## 流程（三步脚本，依次运行）

```
python 下载财报.py          # 第0步：巨潮下载 10 份半年报 → 数据源/
python 01_解析切块/解析切块.py   # 第1步：PDF → 文本块.json（3321块）
python 02_索引/建BM25索引.py     # 第2步a：本地 BM25（纯Python，中文二字元）
python 02_索引/建向量索引.py     # 第2步b：阿里云百炼 text-embedding-v3 向量化
python 03_问答/服务.py           # 第3步：网页问答 http://127.0.0.1:8787
python 04_评测/评测.py           # 第4步：10 题逐题评测 → 04_评测/评测记录.md
```

## 密钥

复制 `.env.example` 为 `.env`，填入：

```
DASHSCOPE_API_KEY=sk-...   # 阿里云百炼（embedding）
DEEPSEEK_API_KEY=sk-...    # DeepSeek（生成）
```

`.env` 已被 `.gitignore` 排除，代码零硬编码 key。

## 检索策略（本作业的核心设计）

1. **双路混合**：向量(0.6) + BM25(0.4)，各归一化后合并取 top-8；
2. **跨公司保障**：问题里点名的公司（支持"茅台/汾酒"等简称），每家强制"公司内部 BM25+向量混合"保底 3 块——防止全局榜单被一家公司垄断；
3. **出处强制**：系统提示词要求每句带 `[F0xxxx]` 角标，编号只能来自所给材料；网页端点角标定位原文块。

## 评测结论（10 题，明细见 `04_评测/评测记录.md`）

- ✓ 对 9 题：单公司事实查找全对（含渠道收入表、每股收益），2~3 家公司比较/排序全对；
- ✗ 翻车 1 题：**10 家公司全景统计**——召回窗口 8 块装不下 10 家，只进了 5 家；
  修复方向：先拆题再分路由检索（课件第 93 页的路由思路），或扩大 top-k 多轮取证。

**一句话结论**：同一批财报，事实查询类问题适合建库——数字必须精确、必须可溯源，
库能给出原文块和页码；微调适合学固定口径文风（如董秘答投资者问），但模型记不住
精确数字，编造风险高。两类问题该走两条路。
